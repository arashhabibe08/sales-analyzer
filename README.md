یک وب‌اپلیکیشن تعاملی و مدرن برای تحلیل داده‌های فروش که با زبان **Python** و کتابخانه **Streamlit** ساخته شده است.

## 🚀 امکانات پروژه
- **آپلود فایل اختصاصی:** کاربر می‌تواند فایل CSV فروشگاه خود را در سایت آپلود کند.
- **پاکسازی و تحلیل:** محاسبه خودکار درآمد کل و شناسایی پرفروش‌ترین محصولات با `Pandas`.
- **نمودارهای تعاملی:** رسم نمودار میله‌ای فروش محصولات با `Matplotlib`.
- **رابط کاربری ریسپانسیو:** طراحی زیبا و قابل استفاده در موبایل و دسکتاپ.
